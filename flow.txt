ASSETROUTER — COMPLETE USER JOURNEY & PAGE FLOW SPECIFICATION
==============================================================================

AssetRouter is a non-custodial Intent Router for Tokenized Assets and Cross-Chain
Yields powered by Flare FTSOv2 decentralized price oracles, Flare FAssets (FXRP),
LI.FI liquidity aggregation, and DeFiLlama analytics.

2. AI INTENT ROUTER PAGE (`/` — App Mode)
------------------------------------------------------------------------------
Primary Goal: Converts natural language financial intents into deterministic,
oracle-verified execution routes.

Step-by-Step User Flow:
1. User sees the Global Top Navigation (`NavBar.tsx`):
   - AssetRouter Logo (redirects to Landing Page)
   - Navigation Tabs: Router, Holdings & Alerts, Yields, Feeds
   - Wallet Connect Controls: "Connect MetaMask" button & "Demo Wallet" switcher.
2. Live Oracle Price Ticker (`PriceTicker.tsx`):
   - Displays sub-second FTSOv2 feeds: FLR/USD, BTC/USD, ETH/USD, XRP/USD.
3. Natural Language Intent Input Box (`IntentForm.tsx`):
   - User types intent e.g., "I have 500 USDC on Base and want low risk yield on Flare".
   - Quick Sample Prompt Pills:
     a. "What can I do with my XRP on Flare?"
     b. "Max yield low risk passive income"
     c. "Liquid stake FLR with instant withdrawal"
   - User clicks "Refine Intent →" or presses Enter.
4. AI Reasoning & Route Generation:
   - Backend parses goal parameters (target APY, risk tolerance, asset, preferred chain).
   - Queries Flare FTSOv2 for live price valuation.
   - Queries DeFiLlama & LI.FI for top liquidity pools.
5. Ranked Strategy Recommendation Cards (`RecommendationCard.tsx`):
   - Displays Strategy #1 ("BEST MATCH"):
     - Badges: BEST MATCH (emerald pill), Low Risk (green pill), score 94/100.
     - Header: Protocol Name (Kinetic), Chain (Flare), Asset Pair, APY (8.42%).
     - 4 Parameter Grid: TVL ($2.41M), Execution fee (0.30%), Lockup (None), Network (Flare).
     - "Why this option?" Checklist:
       ✓ Meets target APY (8.42% ≥ 8.00%)
       ✓ Matches low risk preference
       ✓ Fits liquidity requirement ($2.41M TVL)
       ✓ Low execution fee (0.30%)
       ✓ Preferred chain (Flare)
     - Interactive Controls:
       - "Compare ranking ˅": Expands score breakdown against alternative pools.
       - "● Data sources ˅": Expands verification sources (Flare FTSOv2, DeFiLlama, LI.FI).
       - ROUTE: Displays token path (e.g., XRP → WFLR → FXRP).
       - "View execution steps ˅": Expands step-by-step transaction sequence.
     - 30-Day APY Sparkline Chart: Displays historical APY stability.
   - Ranked Strategies #2 & #3 (Moonwell, SparkDEX) collapsed as expandable accordion cards.
6. Non-EVM XRP Bridge Assistant (`FAssetsCard.tsx`):
   - Rendered when user intent involves XRP.
   - Shows live FTSOv2 XRP/USD price, minimum lot size (10 XRP), minting/redemption fees.
   - Allows entering XRP amount to calculate FXRP minting & protocol staking breakdown.
7. Route Selection & Execution Modal (`RoutePreviewModal.tsx`):
   - User clicks "Select route & execute →".
   - Modal opens displaying optimal LI.FI bridge route, estimated gas fee, receiver address.
   - User confirms route by clicking "Confirm & Execute Route".
8. Execution Status Tracker (`TxStatusCard.tsx`):
   - Displays real-time 3-step transaction progress:
     1. Wallet Signature Request
     2. LI.FI Bridge / Swap Execution
     3. On-Chain Settlement & Position Confirmation.
