# Full Visual Restyle — Replace This App's Design Language

You are re-skinning an existing application so that it looks and FEELS like https://li.fi/.
This is NOT a colour swap. Replace the entire design language — aesthetic direction, surface treatment, depth, effects, motion, and interaction feedback — across EVERY page, route, layout and component.

## Target Aesthetic
Target vibe: **gradient-rich, soft-rounded, high-saturation, technical-mono, editorial-serif, bold-display-type**.
The source design reads as: gradient-rich, soft-rounded, high-saturation, technical-mono, editorial-serif, bold-display-type. It mixes light and dark surfaces. Generously rounded corners (~173px average, up to 24px). Subtle elevation using 2 shadow level(s). Motion: snappy transitions (~125ms average) using cubic-bezier(.44,0,.56,1).

### Step 0 — Remove the current aesthetic first (mandatory)
Before applying anything below, strip the app's existing visual identity so the old vibe cannot bleed through:
- Delete or overwrite old theme values in the global stylesheet (`src/index.css`) and `tailwind.config.ts`.
- Remove hardcoded colour utilities (`bg-white`, `text-black`, `bg-blue-500`, `text-[#hex]`) and replace them with semantic tokens.
- Remove decorative treatments that belong to the OLD style but not the target (e.g. old textures, ornamental borders, retro filters, mismatched display fonts) unless they also appear in the spec below.
- Keep all layout structure, copy, routes and functionality exactly as-is. Only the visual language changes.
